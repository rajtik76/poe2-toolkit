# Changelog

All notable changes to `@poe2-toolkit/mod-extractor` are documented here.
Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
versions follow [Semantic Versioning](https://semver.org/).

## [0.1.3] - 2026-07-17

### Changed

- Bumped the pinned `@poe2-toolkit/ggpk` range from `^0.5.0` to `^0.6.0` to
  match the current minimum version.

## [0.1.2] - 2026-07-17

### Changed

- Shared CLI and icon-decode logic with the other extractor packages;
  tightened row and type safety.

## [0.1.1] - 2026-07-03

### Changed

- Scoped mod joins by domain.

## [0.1.0] - 2026-07-03

### Added

- Initial item-mod extractor.
